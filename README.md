# packwiz-installer
An installer for launching packwiz modpacks with MultiMC. You'll need [the bootstrapper](https://github.com/comp500/packwiz-installer-bootstrap/releases) to actually use this.
This build never deletes files from your game folder. Whenever the installer would normally remove a file, it moves it into a packwiz_Outdated folder inside the pack folder (the game directory) instead.
使packwiz不再直接删除旧mod（或其他文件），而是移动到packwiz_Outdated文件夹
